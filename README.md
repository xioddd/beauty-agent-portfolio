# 美妆内容全链路智能运营 Agent 作品集

这是一个基于 Coze 搭建的美妆品牌内容运营 Agent 作品集。项目目标不是做一次性文案生成，而是把品牌内容运营中的「资料核验、用户洞察、策略分支、内容生成、合规风控、质量评分、反馈迭代」串成一条可复用的智能工作流。

在线作品集入口：

```text
https://xioddd.github.io/beauty-agent-portfolio/
```

## 项目概述

该 Agent 面向美妆品牌内容运营场景，重点解决三类问题：

- 产品资料复杂，容易出现版本混用、卖点遗漏、数值失真。
- 美妆内容合规要求高，容易踩到绝对化、医疗化、无证美白、虚构数据等红线。
- 内容产出不应只停留在「生成文案」，还需要能解释策略、识别风险、接受反馈并迭代。

因此，项目设计了一套从知识库到回归评测的闭环：

```text
知识库 RAG → 资料核验门 → 内容策略分支 → 平台化内容生成 → 合规风控 → 五维评分 → 反馈闭环 → 回归评测
```

## 核心能力

- 资料核验：先检查产品名称、版本、卖点、目标人群、使用场景和信息缺口，再决定是否生成正式内容。
- 平台化输出：根据小红书、抖音、天猫等平台特点，输出不同风格的标题、开头和正文。
- 合规拦截：对绝对化承诺、医疗化表达、无证美白、虚构实验/价格/用户评价等高风险内容进行拦截和改写。
- 版本确认：当用户只说系列名但未说明版本时，先反问确认，避免把不同代际产品信息混用。
- 多产品搭配：支持早 C 晚 A、双抗精华与红宝石系列等多产品咨询，先检索知识库再回答。
- 反馈迭代：用户选择「采用」或「需要修改」后，Agent 会基于反馈输出修改版并说明优化点。

## 评测与迭代结果

项目使用固定评测集进行回归验证，并从 v2.2 迭代到 v2.3.1。

| 指标 | v2.2 基线 | v2.3.1 回归 |
|---|---:|---:|
| 冒烟总体通过率 | 82.5%（33/40） | 100%（40/40） |
| 合规对抗 | 60%（6/10） | 100%（30/30 次运行） |
| 跨版本准确性 | 88.9%（8/9） | 100%（27/27 次运行） |
| 正例 / 拒答 / 多平台 | 86.7% / 100% / 100% | 100% / 100% / 100% |

v2.3.1 的核心改动是把高频合规红线从「依赖 RAG 概率召回」升级为「系统提示词内置的确定性规则」，并补充关键事实保真、版本确认前置、多产品咨询放行等规则。最终在 78 次加严回归中全部通过。

## 作品集看点

- 不只展示 Agent 能生成什么，也展示了如何定义评测集、定位失败原因、做确定性修复和回归验证。
- 保留了 T049 医疗化高风险用例的三次独立实测证据，体现对合规稳定性的验证。
- 用数据讲清楚 v2.2 到 v2.3.1 的改进路径：从 82.5% 到 100%，并且 33 条原通过用例零回归。
