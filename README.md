# 美妆内容全链路智能运营 Agent 作品集

这是用于 GitHub Pages / Vercel / Netlify 部署的静态作品集版本。

## 文件结构

- `index.html`：作品集首页
- `assets/screenshots/`：页面引用的截图素材
- `.nojekyll`：让 GitHub Pages 直接按静态文件托管

## GitHub Pages 发布步骤

1. 在 GitHub 新建一个公开仓库，例如 `beauty-agent-portfolio`。
2. 上传本目录 `github-pages` 里的所有文件和文件夹到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. 保存后等待 1-3 分钟，页面会生成在线链接。

最终链接通常是：

```text
https://你的GitHub用户名.github.io/beauty-agent-portfolio/
```

## 给 HR 的推荐交付方式

邮件或简历中放在线链接，同时附 PDF 或完整材料包作为备份。
